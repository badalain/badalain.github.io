# Badalain

A free, static website (HTML, CSS and JavaScript; no framework, no build step)
that lists documented ownership links between consumer brands and
organizations, with a source and date for each claim, and suggests
alternatives.

## Files
- `index.html`, `styles.css`, `app.js` — the site
- `data.js` — the English data (brands, owners, sources)
- `ur.js` — Urdu text; not yet reviewed by a professional translator
- `sw.js`, `manifest.json` — offline use and installation
- `robots.txt`, `sitemap.xml`, icons

## Data method
Each entry is marked **verified** (confirmed against a primary document such
as an annual report's pattern of shareholding, a regulator filing, or the
owner's own website) or **lead** (from a secondary source, not yet confirmed).
Exact percentages are shown as published; minority stakes are never described
as full ownership. Each entry gives its sources and the date accessed.

## Corrections
Use the Suggest / correct form on the site, with a source link.

## Privacy
No accounts, ads, analytics or tracking. Searches run on the visitor's own
device.
